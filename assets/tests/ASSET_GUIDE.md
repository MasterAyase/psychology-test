# 测试内部图像资产规范

## 命名与目录

- 路径：`assets/tests/<测试 id>/<用途>/`。
- 文件名使用测试数据中的稳定英文 id，例如 `owl.webp`、`zhugeliang.webp`。
- 响应式版本在 id 后追加像素宽度，例如 `owl-300.webp`、`zhugeliang-240.webp`。
- 授权与来源写入同目录的 `SOURCES.md`，不得只保存在提交信息或聊天记录中。

## 尺寸与压缩

| 用途 | 主文件 | 小屏版本 | 单文件建议上限 |
|---|---:|---:|---:|
| MBTI 横版场景插画 | 720×480 WebP | 360×240 WebP | 90 KB / 35 KB |
| 恋爱类型横版插画 | 720×480 WebP | 360×240 WebP | 90 KB / 35 KB |
| 人物竖版肖像 | 480×640 WebP | 240×320 WebP | 80 KB / 25 KB |
| 动物竖版插画 | 1200×1600 WebP | 600×800 / 300×400 WebP | 280 KB / 95 KB / 30 KB |
| 塔罗牌面 | 500×857 WebP | 浏览器懒加载 | 160 KB |

压缩后必须检查人物面部、文字边缘、牌面符号和透明边缘。不得为了体积强行降低到影响识别的质量。

## 页面接入

- 所有内容图像必须提供准确的 `width`、`height` 与有意义的 `alt`。
- 图鉴列表使用 `loading="lazy"` 与 `decoding="async"`；首屏当前结果封面才使用 `loading="eager"` 和 `fetchpriority="high"`。
- 有小屏版本时提供 `srcset` 与 `sizes`，不要让 360px 设备下载完整大图。
- 图像失败后隐藏破损图标，名称、摘要与操作仍必须可读。
- 图片只承担识别和氛围，不承载唯一的结果信息。

## 新增资产检查

1. 核对稳定 id、尺寸和文件体积。
2. 在 `SOURCES.md` 记录作者、原始页面、许可或生成方式。
3. 生成响应式版本并在真实页面接入。
4. 在 360px 慢速网络、1440px 桌面和深色主题验证布局。
5. 检查图片失败时的文字降级与控制台错误。
