# 动物人格插画来源

本目录 12 组动物插画由 OpenAI 图像生成工具按 Wingsight（翼眸）的自然观察手册方向生成，未使用第三方照片或插画作为直接输入。

- 高分辨率版本：1200×1600 WebP，由主文件高质量放大并轻度锐化，用于高像素密度屏幕。
- 标准版本：600×800 WebP。
- 小屏版本：300×400 WebP，由标准版本等比压缩生成。
- 用途：Wingsight（翼眸）动物人格测试的结果封面、自然观察图鉴和详情抽屉。
- 文件 id：`owl`、`fox`、`cat`、`dog`、`wolf`、`rabbit`、`lion`、`panda`、`sloth`、`eagle`、`capybara`、`dolphin`。
