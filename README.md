# 缘分星盘 · Fate Chart

以生辰八字看正缘的趣味测算网站，附带一个心理测评子站。纯静态页面，免费、无需注册，所有计算都在浏览器里完成。

在线访问：https://masterayase.github.io/psychology-test/

## 功能

- **八字正缘**：排四柱八字，给出五行分布、夫妻宫、正缘画像（五行、性格、方位、幸运色）、属相宜忌、桃花星和未来十年姻缘年份。
- **双人合婚**：从宿曜关系、生肖合冲、日柱合冲、五行互补和配偶星五个方面打分。
- **星宿查询**：按宿曜法由农历生日查本命宿，可加对方生日看两人关系；附二十七宿一览。
- **心理测评**（`psych/` 子目录）：大五人格、16 型人格倾向、恋爱依恋风格、塔罗指引。

## 计算说明

- 农历换算使用浏览器内置的 `Intl` 中国历法。
- 年柱以立春为界，月柱以节气为界；节气时刻用 Meeus 低精度太阳黄经公式计算，误差约十几分钟。
- 日柱按儒略日推算，时柱按五鼠遁；按北京时间排盘，子时按 0 点计算。
- 测算解读由程序按传统说法生成，仅供娱乐参考。

## 本地运行

```bash
python -m http.server 8080
```

打开 http://localhost:8080 。

```
js/art.js           国风线描图案
js/main.js          页面与路由
psych/              心理测评子站（结构见 psych/js）
```
